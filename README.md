# ResearchAI 🔬

A modular multi-agent research assistant built with:

- CrewAI
- Groq GPT-OSS 120B
- Streamlit
- Serper
- Web scraping tools

## Agents

1. Research Planner
2. Web Researcher
3. Academic Analyst
4. Citation Validator
5. Research Writer

## Architecture

User → Streamlit → CrewAI → Research Agents → Final Report

## Deployment

Designed for deployment on Streamlit Community Cloud.
